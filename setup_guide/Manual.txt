===================================================================
                  KISANSETU - RUNTIME MANUAL
===================================================================

PREREQUISITES:
  - Node.js (v18 or higher recommended)
  - npm (bundled with Node.js)
  - Python (v3.9 or higher recommended)
  - pip (bundled with Python)

IMPORTANT: 
  - Ensure you have completed the initial setup steps outlined in 
    'SetupManual.txt' before using these commands.
  - Open two separate terminal windows/tabs to run the stack.

-------------------------------------------------------------------
TERMINAL 1: FRONTEND DEVELOPMENT SERVER (Port 3000)
-------------------------------------------------------------------
Step 1: Navigate to the project root directory and start Vite:
        npm run dev

Step 2: Access the application in your browser:
        http://localhost:3000

-------------------------------------------------------------------
TERMINAL 2: BACKEND FASTAPI SERVER (Port 8000)
-------------------------------------------------------------------
Step 1: Navigate to the backend directory:
        cd backend

Step 2: Activate the virtual environment:
        - Windows (Command Prompt/PowerShell):
          venv\Scripts\activate

        - macOS / Linux:
          source venv/bin/activate

Step 3: Start the FastAPI API server:
        uvicorn main:app --reload --host 0.0.0.0 --port 8000
