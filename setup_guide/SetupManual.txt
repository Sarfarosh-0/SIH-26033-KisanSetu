===================================================================
                KISANSETU - FIRST-TIME SETUP GUIDE
===================================================================

-------------------------------------------------------------------
OPTION A: FULL-STACK SETUP & RUN (RECOMMENDED)
-------------------------------------------------------------------

Step 1: Install Frontend Dependencies
        Navigate to the root directory and run:
        npm install

Step 2: Navigate to the Backend Directory
        cd backend

Step 3: Create & Activate Python Virtual Environment
        - Create virtual environment:
          python -m venv venv

        - Activate virtual environment:
          * Windows:       venv\Scripts\activate
          * macOS/Linux:   source venv/bin/activate

Step 4: Install Backend Dependencies & Seed Database
        pip install -r requirements.txt
        python seed_data.py

Step 5: Start Backend API Server
        uvicorn main:app --reload --host 0.0.0.0 --port 8000

Step 6: Start Frontend Development Server (In a new terminal window)
        From the project root directory, run:
        npm run dev

-------------------------------------------------------------------
OPTION B: FRONTEND ONLY
-------------------------------------------------------------------

Step 1: From the root directory, install dependencies:
        npm install

Step 2: Start the frontend server (runs on http://localhost:3000):
        npm run dev

-------------------------------------------------------------------
OPTION C: BACKEND ONLY
-------------------------------------------------------------------

Step 1: Navigate to the backend directory:
        cd backend

Step 2: Activate virtual environment:
        * Windows:       venv\Scripts\activate
        * macOS/Linux:   source venv/bin/activate

Step 3: Install dependencies:
        pip install -r requirements.txt

Step 4: Seed database (optional/recommended for demo data):
        python seed_data.py

Step 5: Start backend server (runs on http://localhost:8000):
        uvicorn main:app --reload --host 0.0.0.0 --port 8000
